# 特定商取引法に基づく表記

最終更新: 2026年10月3日

| 項目 | 内容 |
|---|---|
| 販売事業者 | 〔LEGAL_SELLER_NAME〕 |
| 代表者または運営責任者 | 〔LEGAL_REPRESENTATIVE。設定した場合だけ表示〕 |
| 所在地 | 〔LEGAL_ADDRESS。ON_REQUEST のときは「請求があれば遅滞なく開示します。下記のメールアドレスへご請求ください。」〕 |
| 電話番号 | 〔LEGAL_PHONE。ON_REQUEST のときは同上〕 |
| メールアドレス | 〔LEGAL_EMAIL〕 |
| 販売価格 | 月ごと: 〔Stripe の月額の価格〕／年ごと: 〔Stripe の年額の価格〕（読めないときは「購入画面に表示します。」）。〔LEGAL_PRICE_NOTE。例: 表示価格は税込です〕 |
| 商品代金以外の必要料金 | インターネットの接続に必要な通信料金は、お客様のご負担となります。 |
| 支払方法 | クレジットカードなど、Stripe の決済画面に表示される方法 |
| 支払時期 | お申し込みの時に初回の料金を請求し、以降はお選びいただいた契約期間（月ごと・年ごと）の更新日に自動で請求します。〔STRIPE_TRIAL_DAYS が 1 以上のとき:「○日間の無料体験期間がある場合は、体験期間の終了時に初回の料金を請求します。」〕 |
| 提供時期 | 決済の完了後、すぐにご利用いただけます。 |
| 契約期間と自動更新 | お申し込み時にお選びいただいた期間（月ごと・年ごと）。解約しない限り、同じ期間で自動的に更新されます。 |
| 解約の方法 | 設定の「CatchWords Pro」→「サブスクリプションを管理」から、いつでも解約できます。解約すると次の更新日以降は請求されず、支払い済みの期間の終わりまでご利用いただけます。 |
| 返品・返金 | デジタルサービスの性質上、法令で必要な場合を除き、お支払い後の返金（期間の途中で解約した場合の日割りの返金を含みます）は行いません。 |
| 動作環境 | インターネットに接続した端末の Web ブラウザ（有料プランの購入は Web 版でのみ受け付けています） |
