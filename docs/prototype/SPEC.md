# カードキャッチ — デモで決まった仕様（iOS へそのまま移す）

オーナー指示（2026-10-02）: **デモで決めたことを一つずつ、そのまま忠実に再現する。勝手に変えない。**
今の iOS の撮影の流れは置き換えてよい。

- 正しい答えは常に `cardcatch-src.html`（デモのソース。`/*__DATA__*/` と `__ASSETS__` は組み立て時に差し込む）。
  動く完成品は `cardcatch-demo.html`（ブラウザで開ける）。数値・色・時間・順番はソースから写す。
- デモの画面は 390×844pt（iPhone 15 相当）。座標はこの基準。iOS では画面サイズに合わせて同じ比率で置く。
- `D(ms)` は「動きを減らす」設定で 0 に近づく時間。iOS では Reduce Motion で同じ扱い。
- ここに無いこと・デモに無いことは足さない。分からない所はオーナーに聞く。

## 0. 決まった組み合わせ（パネルの選択肢のうち採用されたもの）

## 1. カメラ
- 撮影: `shoot()` — シャッター音、白フラッシュ（0→1 at 12%→0、480ms、ease-out）、写真が止まる（`.frozen`）、シャッター・ファインダー枠を隠す。260ms 後に分析へ。

## 2. AI 分析（フォーカス）
- `analyze()` + `anaFocus()`。
- ピル: 上部中央（top 112pt）、白 90% のすりガラス、左に青いグラデーションの角丸アイコン（`.spark`、回転する conic 青だけ）、文字は **「AIが分析中…」だけ**（サブ文は分析中は隠す）。
- 画面の縁が青く光る（`.aiglow`、青だけの conic、内側 7pt の輪＋ぼかし 18pt）。
- 四隅の白い枠（`.bracket`、22pt の L 字、太さ 3、白、外側に水色の光）が画面全体 (26,120,338×520) に出てから、物ごとに順に「物の囲み＋14pt」へばねで移動（540ms, cubic-bezier(.3,1.3,.5,1)）→ 音 tick → その物の輪郭が光る → 枠が 0.94 に縮んで戻る（260ms）→ 400ms 待つ。全部終わったら枠は 300ms で消える。
- 物の輪郭（`outlineEl`）: 切り抜きの形をそのまま水色グラデーション（#BFE8FF→#9CC8FF→#CFE3FF）で縁取り（3.5pt ずらし 20 方向）＋外側に光。
- 終わり: 縁の光を消す。ピルは「Nつ見つかりました」＋サブ「タップして選んでください」。見つかった音（`SFX.found`）。

## 3. 物を選ぶ
- `showPick()`: 輪郭はゆっくり点滅（`.pulse`、2s）。物ごとに白いタグ（青い点が波紋、物の名前）を物の上に 140ms + i×130ms でポンと出す（`SFX.pop`）。下に「撮り直す」ボタン。物の範囲をタップしても選べる。

## 4. 言葉を選ぶ（シート）
- `pickObject()`: 下からシート（白 94% すりガラス、角 28）。題「「◯◯」をどの言葉で集める？」と × ボタン。
- 候補の行（`.wrow`）: 漢字 32pt 太さ 500 ＋注音 / 日本語の意味（ピンインは注音を出す時は出さない）/ 右に青い丸の発音ボタン。行は 90ms ずつずらして下から出る（300ms）。
- 160ms 後に候補の音（`SFX.cands`、候補 1 つにつき 1 音）。

## 5. 光に変わる → カード
- `chooseWord()` → `formLight()`。
- 背景がカテゴリーの色に変わる（`.catbg`: 中心白→b1→b2→b2 を暗く、放射状。白い光の筋がゆっくり回る。0.35s で出る）。写真はぼかして暗く（`.dim`）。
- **切り抜きだけ**（元の写真の四角は出さない）が物の位置で 1→0.08 に縮み、明るくなって消える（700ms）。同時に星（`.starlight`、4 角の星 50pt、白く光る）が物の中心に現れ（260ms 後、520ms）、周りにきらめき。
- 星がカードの中心 (195,346) へ弧を描いて飛ぶ（600ms、途中で 180° 回る、光の尾）。音 `SFX.fly`。
- カードが回って出る: rotateY 720°→360°→0（鏡文字が見えない回り方）。詳細は `formLight` の後半。
- その後: 発音（`say`）、光が走る（`.sweep`）、はじける粒、きらめき、後光（`.halo`）、ぼけ玉。
- 下に「カードを動かしてみよう・上にはじいて図鑑へ」と、白い丸の発音ボタン、青い「↑ 図鑑に入れる」ボタン（top 566pt）。
- カードは指で傾けられる（`tilt()`）。上にはじくと図鑑へ。

## 6. ホログラムカード d2（デザインは変えない）
- 280×392pt、角 16。`cardHTML` の d2 と `.d2 *` の CSS をそのまま。
- 背景: カテゴリー色のスタジオ（`artLayers` の cut）。
- 上の白いバー: left/right/top 14、高さ 48、角 12、白 88%＋ぼかし、名前（漢字 28pt 太さ 700＋注音）と右に No.001（13pt 900）。
- 下の白いパネル: left/right/bottom 14、角 12、白 90%。日本語の意味 16pt 900、例文（繁體字 11pt）、訳 9.5pt、下段に「カテゴリー・品詞」と「場所 · 日付」9pt。
- 物（切り抜き）: **できるだけ大きく**。白い箱の余白にははみ出してよいが、文字には重ねない・カードの外には出さない（`bigPop`: 不透明な画素が x 7–273, y ≥ 7、名前・No.・下の文字の四角から 4pt 離れる。下端は y=293 に置き、高さ 287 から小さくしていって最初に収まる大きさ）。カードと一体（浮かせない、影は小さく `drop-shadow(0 3px 4px rgba(0,20,50,.22))`）。
- 虹色の箔・きらめき・縁の虹（`.foil` `.glit` `.rim`）は傾きで動く（iOS では既存の holoFoil と傾きを使ってよい）。

## 7. 図鑑へ
- `sendToDex()`: カードが少し持ち上がる（260ms）→ 星が現れ、カードは縮んで消える（420ms）→ 背景を戻す → **図鑑の一覧（カテゴリー）を開く** → 入る場所へスクロール → 600ms 後、星が弧を描いてその影へ飛ぶ（720ms）→ 着地でポン（`.landpop`、`SFX.pop`＋振動）→ 影の所に切り抜きが現れる（`.slot.fill`、1.7 倍から戻る）。

## 8. 図鑑
- 上部に 4 つの丸ボタン（カード=スライド / 地図 / ギャラリー=影 / リスト）。`#dxSeg`。
- ギャラリー: カテゴリーごとの白い箱、4 列、影（シルエット）、No.、捕まえると切り抜きと名前、捕まえていない所は「？？？」。`renderDex` の grid。
- スライド: Web 版の再現（リング、ばね、背景、スライド音）。iOS は既存の DexCoverFlow。
- 地図・リスト: `renderDex` の map / list。

## 9. 音
- 合成音はデモの WebAudio（`SFX` オブジェクト）を音声ファイルに書き出して使う。
- 効果音オフで全部止まる。振動は振動の設定に従う。
