カードキャッチ試作

撮る → AIが分析 → 写っている物をタップ → 言葉を選ぶ → 写真がそのままホログラムカードになり発音が流れる → 図鑑へ。案を切り替えながら右の画面で試せます。音が出ます。

決まった組み合わせ

分析：フォーカス／カードの背景：種類の色／カードの生まれ方：光に変わる（星の光）／デザイン：フルアート

図鑑の見せ方

音

カメラアイコン→シャッターの動き（押すと見本が動く）

単語の候補が出る音（押すと試聴）

光に変わる音（カードが出る前・図鑑に入る時／押すと試聴）

動き

カメラロールの写真は、AI（あなたの Claude）が写っている物と単語を推定します。最初に使うとき確認が出ます。カメラロールの写真は切り抜けないため「元の背景」になります。試す場面は、物の位置と切り抜きをあらかじめ用意したサンプルです。効果音はその場で合成しています。図鑑のスライド音は Lovable の Web版と同じ音声ファイルです。
