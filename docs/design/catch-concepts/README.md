# キャッチ演出 4案 v3（コンセプト動画の素材と作り方）

撮った物の名前を選んで図鑑に入れるまでの演出を、4案（A〜D）と、単語の詳細を開いたときの待ち時間（E）の動画にしたときの素材一式です。
アプリのコードはまだ変えていません。採用する案が決まったら、ここの効果音・振動・寸法を使って SwiftUI で実装します。

動画と比較表・設計の説明は Artifact のページにあります（オーナーの claude.ai アカウントで閲覧）。

## v3 で変えたこと

- **言い方の選択（全案）**：Web版の候補選択（`CandidatePicker`）と同じ作りです。
  - ふだんの言い方を一番大きく出し、下に「ほかの言い方」を並べます。
  - それぞれにレジスターの印（砕けた言い方／くわしい名前）、意味、いつ使うかの一言を付けます。
  - 例は 珍珠奶茶 / 珍奶 / 波霸奶茶 で、動画では 珍奶 を選んでいます。
- **図鑑全体への追加（全案）**：図鑑ページは全カテゴリーを開いたまま出し、該当カテゴリーまでスクロールしてから自分の枠に入れます。
  - 寸法はアプリの `DexGallery` と同じです。
- **ゲームを参考にしたご褒美**：予感、0.07秒のため、衝撃、NEW、回るカウンター、次の影の補充、「あと1語でコンプリート」を入れています。
- **B のシールは最後まで剥がす**：Blender（Cycles）で描画しています。
- **AI の待ち時間**：待ち時間の演出は「下書き → 清書」の考え方で作りました。待ちそのものを減らす設計はページにまとめています。
- **E（単語の詳細）**：初回に解説を生成する間の演出です。

## アプリへの実装で必要なこと

- **言い方の候補と図鑑の枠をつなぐ**：どの言い方を選んでも、図鑑では同じ物の枠に入る必要があります。
  - 例：珍奶 を選んでも No.001 タピオカミルクティーの枠に入れます。
  - 候補を物ごとに束ねる番号（`group`）を使って、図鑑の項目とつなぎます。
- **図鑑への追加は単語カードの生成を待たない**：今は「図鑑に追加」ボタンが `generateCard` の完了を待っています。
  - ことば・読み・意味・切り抜きは候補の時点でそろっているので、先に図鑑へ入れられます。
  - 保存は裏で行います。
- **発音は候補が届いた時点で先読みする。**
- **持っている単語かの確認は候補が届いた時点でまとめて行う**：タップのときに待たせないためです。

## フォルダ

- `film/`：動画を描くページと書き出しスクリプトです。
  - ページ：`film.html` + `js/`
    - `core.js`：計算、文字と注音、iOS の部品
    - `sketch.js`：解析中の下書きと清書
    - `picker.js`：言い方の選択
    - `dex.js`：図鑑とフィナーレ
    - `concepts.js`：A〜D
    - `detail.js`：E
  - 書き出し：`render.js`（60fps）、`cues.js`（音のためのタイミング書き出し）
  - `film/assets/dex/`：図鑑に並ぶ物の切り抜きと影
    - 写真は Figma の画像生成（24点）と、v2 の ElevenLabs 生成写真です。
    - 背景除去は rembg（isnet）です。
  - `film/assets/contours.json`：解析中に描く物の輪郭
  - `film/assets/phosphor.json`：影に使った Phosphor Icons（MIT ライセンス）の形
  - `film/blender/peel.py`：B の「剥がしきって表に返す」描画スクリプト
    - 描画したコマはサイズが大きいので含めていません。
- `audio/`：音です。
  - `audio/tools/mix3.py`：5本のミックス
  - `audio/tools/kit3.py`：アプリ用キットと振動パターン
  - `audio/kit3/caf/`：アプリ用の効果音37種（48 kHz・CAF）。音量は役割ごとにそろえています。
    - 待ちの音 -32 LUFS
    - UI音 -26
    - 動きの音 -24
    - 合図の音 -21
    - 着地 -19
  - `audio/kit3/haptics/*.ahap`：Core Haptics の振動パターン8種。
    - 着地のパターンは、着地の0.37秒前から始めます。
  - `audio/cues3.json`：動画から書き出した各イベントの時刻
  - `audio/raw/`：ElevenLabs で生成した元の音
    - 「珍奶」の発音（文字起こしで確認済み）
    - 着地の質感とライザー
- v2 の素材（`audio/kit/` など）も残しています。

## 待ち時間の演出（下書き → 清書）

- AI が考えている間は、分かっていることを鉛筆の下書きで描きます。下書きは完成形と同じ場所・同じ形です。
- 答えが届いた瞬間に、その上をなぞって清書します。
- **キャッチ**：写真の上に白い線で描きます。
  - 撮影0.5秒後、端末内で切り抜いた物の形を描きます。
  - 名前の入る場所には鉛筆の枠を描きます。
  - 名前が届いたら、一つずつ清書します。
- **詳細**：紙の上に青鉛筆で描きます。
  - 分かっている情報は最初から清書で出します。
  - AI が書く項目は、行ごとに下書きが育ちます。
  - 届いたら、上から順に清書します。
- **待った時間ごとの見せ方**：
  - 0.3秒まで：何も出しません。
  - 0.3〜1秒：下書きを出したら、最低0.4秒は見せます。
  - 1〜5秒：動画のとおりです。
  - 5秒以上：状態の言葉を変えます。
  - 10秒以上：裏で続け、できたら知らせます。

## 作り直し方

前提として、次のものが必要です。

- Python 3.11 と numpy、scipy、pyloudnorm、rembg
- Node.js と Playwright（Chromium）
- ffmpeg
- Blender 4.0（Python 3.12 側にも numpy が必要）

```sh
cd docs/design/catch-concepts
# 1. B の剥がし（約75分、4コア）
blender -b -P film/blender/peel.py -- film/blender/peel_full 48
# 2. 動画のタイミングを書き出して、音を作る
cd film && npm install lottie-web@5.12.2 playwright
python3 -m http.server 8765 --bind 127.0.0.1 &
node cues.js > ../audio/cues3.json
cd .. && python3 audio/tools/mix3.py A audio/mixes3/A.wav   # B〜E も同様
python3 audio/tools/kit3.py
# 3. 映像（60fps で1コマずつ描いて書き出す）
cd film && node render.js A A.mp4 ../audio/mixes3/A.wav
```
