# キャッチ演出 v6（スキャン・ゲット・解説の待ち時間の動画の素材と作り方）

撮影から図鑑に入るまでと、単語の詳細の待ち時間を、動画にしたときの素材一式です。
アプリのコードはまだ変えていません。ここの寸法・タイミング・効果音を使って SwiftUI で実装します。

動画と設計の説明は Artifact のページにあります（オーナーの claude.ai アカウントで閲覧）。

| 動画 | 内容 |
| --- | --- |
| F 通し | P1＋四角い枠 → 標準のタグ → D の選択 → ゲットの場面 → 図鑑。名前が届くのはシャッターの6.0秒後（実測の中央値） |
| S 遅い場合 | 同じスキャンで、名前が届くのが11.5秒後（実測の90パーセンタイル）。タップまで |
| E 単語の詳細 | 書いている間は欄に何も出さず、書き終わった瞬間に光がなぞって文字が現れる |

## v6 で変えたこと

- **P1・標準・D の通し**：オーナーが選んだ組み合わせを1本にしました。P1 の光の動きと D の選択画面は v5 のままです。
- **四角い枠（古い iOS の動きのまま）**：消した解析画面の FocusBrackets（git `9fca1bc^` の `Views/AnalyzingView.swift`）を、そのまま使っています。
  - 見た目と動き：
    - 四隅の線、#BFEFFF、2.5pt。
    - シアンの光（`.shadow(Theme.cyan 0.8, radius 6)`）。
    - 腕の長さは短い辺の22%。
    - 1.25倍・透明から、ばね（response 0.38、damping 0.62）で縮んで付き、`Haptics.selection()` が鳴ります。
    - 最初は物が見つかった250ミリ秒後、以降は380ミリ秒ごとに付きます。
    - 付いた後は 1.0 ↔ 1.02 で呼吸します（1.1秒ずつ）。
  - 違うのは位置だけ：毎回、その写真の物の切り抜き（`VNGenerateForegroundInstanceMaskRequest`）を囲む四角に付きます。前の画面は写真に関係なく毎回同じだったため、オーナーが消しました。
  - 枠が付いた物から順に、P1 の光がその物の輪郭を一周します。
  - 名前が届くと、その物の枠が消えてタグが出ます（タグを出す時刻は v5 と同じ `max(スキャン完了, 名前の到着)`）。
- **実際の待ち時間**：Web アプリの本番の記録（同じサーバと AI）から測りました（2026-10-03〜10、`ai_runs` 表）。

  | 測ったところ | 回数 | 中央値 | 90% |
  | --- | --- | --- | --- |
  | 撮影 → 名前の候補が画面に出る | 22 | 6.0秒 | 11.5秒 |
  | 選ぶ → 解説が出る（新しく作る） | 10 | 11.2秒 | 18.9秒 |
  | 選ぶ → 解説が出る（作成済み） | 17 | 0.27秒 | — |

  - 回数が少ないので、利用が増えると数字は動きます。くわしくは `LATENCY.md` の「0. 実測」。
- **ゲットの場面**：v5 では、選んだ単語が約0.8秒で消えていました。今回は約2.5秒出ています。流れは次のとおりです。
  1. 選ぶとカップがステッカーになって舞台の中央に出ます。
  2. 読み上げに合わせて「珍」「奶」が1文字ずつ現れます。音声の中で各音節が始まる時刻に合わせています。
  3. 意味が続き、「新しいことばをキャッチ！」が出ます。
  4. 図鑑へ飛びます。
- **背景（作り直し）**：光の筋（サンバースト）はオーナーの判断で却下しました。代わりに照明の当たった展示台にしています。
  - 壁が床へ曲がって続く背景、上からの光、床の光だまり、影と映り込み、光の中の粒でできています。
  - 物の周りの光は、物の切り抜きの代表色（k-means）で温めます。物ごとに色が変わります。
- **E**：書いている間、解説の欄には何も出しません（点もなし）。
  - 書き終わった瞬間に、光が1行ずつ左から右へなぞり、光の粒が集まった所から文字が現れます。
  - 待ち時間は5.3秒で描いています。解説を選んだ瞬間に裏で作り始めた場合の値です（中央値11.2秒から、ゲット・図鑑・タップの約5.9秒を引いたもの）。
- **音**：`audio/tools/mix6.py`。v5 の輪郭の音（空気のような雑音に7Hzで揺れる高い音を重ねたもの）は、オーナーの判断で却下しました。全体を1つのセットとして作り直しています。

  | 場面 | 音 |
  | --- | --- |
  | 枠が付く | 小さな機械音2つ＋澄んだ音 |
  | 輪郭 | 揺れのない柔らかいガラスの音。光の位置に合わせて左右に動く |
  | 閉じる | 鈴。物ごとに高く |
  | 待つ間 | 揺れのない低い和音 |
  | タグ | v5 のまま |
  | ゲット | 舞台の和音、読み上げ、キャッチの音 |
  | 図鑑 | v5 のまま |
  | E | 1行ごとに鈴2つ |

- **私が足した演出（不要なら外す）**：
  - ゲットの場面：見出し、NEW と番号、星、虹色の光沢、床の光の輪、光の粒、影と映り込み。
  - E：欄のふちの光、書き終わりの星。

## アプリで使う端末内の機能（Apple 公式ドキュメントで確認）

| 用途 | 機能 | 対応 OS |
| --- | --- | --- |
| 枠の位置と P1 の輪郭 | Vision `VNGenerateForegroundInstanceMaskRequest`（目立つ物を背景から分ける切り抜き）。今のアプリの `CutoutService.instanceMasks`（`Services/ImageTools.swift`）と同じもので、`CaptureViewModel` の `masksTask` が AI と並行して計算している | iOS 17 以降 |
| （参考）被写体の一覧 | VisionKit `ImageAnalysisInteraction.subjects` | iOS 16 以降 |

アプリの最小対応は iOS 18 なので使えます。目立たない背景の物（この写真の植え込み）は切り抜けないことがあります。その物には枠を付けず、名前だけ出します。物が1つも見つからない写真では、枠と光を省き、状態の表示だけで待ちます。

## フォルダ

- `film/`：動画を描くページと書き出しスクリプト
  - v6：`film6.html` + `js/core6.js`（`?ai=` で待ち時間を変えられる）、`js/p1b.js`（P1＋枠）、`js/concepts6.js`（通し・D・ゲット・舞台）、`js/detail6.js`（E）
  - v6 の書き出し：`render6.js`（60fps）、`preview6.js`（複数時刻の一覧画像）、`crop6.js`（1コマの拡大）、`cues6.js`（音のためのタイミング書き出し）
  - 共通：`js/tags.js`（タグ）、`js/scan.js`（切り抜きの読み込み・状態の表示）、`js/picker.js`（言い方の選択）、`js/dex.js`（図鑑と着地）
  - v5：`film.html` + `js/core.js`、`js/p1_lift.js` など（下の「v5 の記録」）
  - `masks/`：写真の中の物の切り抜き、輪郭（`outlines.json`）、奥行き、エッジ。作ったスクリプトは `masks/tools/`
  - `fonts/`：Noto Sans JP / TC（必要な文字だけにした版）と Inter
  - `assets/`：写真、カップの切り抜き、図鑑の物の切り抜きと影
- `audio/`：音
  - `audio/tools/mix6.py`：v6 の3本のミックス。ニ長調、鳴った場所の左右、-16 LUFS・ピーク -1 dBTP
  - `audio/cues6.json`：動画から書き出した各イベントの時刻
  - `audio/*_cues_v6.json`：各動画の音のイベント一覧（振動の指定つき）
  - `audio/kit3/`：アプリ用の効果音と振動パターン（v3）、`audio/raw/`：元の音（ElevenLabs で生成した発音・質感など）
- `LATENCY.md`：待ち時間を短くする設計と、実測の数字

## 作り直し方（v6）

必要なもの：Python 3.11（numpy、scipy、pyloudnorm）、Node.js と Playwright（Chromium）、ffmpeg。

```sh
cd docs/design/catch-concepts/film
npm install lottie-web@5.12.2 playwright
python3 -m http.server 8765 --bind 127.0.0.1 &
# 1. タイミングを書き出して、音を作る
node cues6.js
cd ../audio && mkdir -p mixes6
python3 tools/mix6.py F mixes6/F.wav && python3 tools/mix6.py S mixes6/S.wav && python3 tools/mix6.py E mixes6/E.wav
# 2. 映像（60fps で1コマずつ描いて書き出す）。遅い場合は AI=11.5 を付ける
cd ../film
node render6.js F F.mp4 ../audio/mixes6/F.wav
AI=11.5 node render6.js S S.mp4 ../audio/mixes6/S.wav
node render6.js E E.mp4 ../audio/mixes6/E.wav
```

`render6.js` などは Chromium の場所を `/opt/pw-browsers/...` に決め打ちしています。別の環境では書き換えてください。

## v5 の記録

v5 では、スキャン3案（P1 被写体リフト・P2 深度スキャン・P3 輪郭解析）、名前の待ち方3案（S1 影あわせ・S2 パタパタ・S3 粒子）、タップ後の2案（A・D）、E（点に崩れて左から文字に戻る）を作りました。オーナーが P1・標準・D を選んだので、v6 はその組み合わせです。v5 の動画は `film.html`（`node render.js P1 …`）と `audio/tools/mix5.py` で作り直せます。

## 使えなかったツール

- **Mobbin**：この作業環境からは接続が拒否されました。参考にしたのは iPhone の写真アプリの「被写体を背景から持ち上げる」動き（iOS 16 以降）です。
- **Rive**：編集画面に入れないため使っていません。
