# Web 版の過去の言語混在の事例と、iOS 版での対応

Web版（Lovable）のコードの注記・試験・コミットにある、言語が混ざった報告をすべて集めた表。
各事例の具体的な文は `ios/LanguageRules/cases.json` に `W-` で始まる id で入っていて、CI が毎回確かめる。
規則の番号は `docs/language-rules.md` を参照。

状態：**対応済み**＝iOS で同じ形が起きない／**対応中**＝直している途中（下の「iOS の残り」）

## 意図して Web と違えている所

- **台湾華語の読者向けの中文の注記に、かなの語を引用している場合**（例：「すし」是從日文來的詞）。
  Web はかなが1文字でもあれば日本語として落とすが、iOS は引用（「」内）を判定から外して残す（R9、ケース IOS2）。
  日本語を学ぶ台湾の人の解説では、かなの語を引用するのが普通だから。
