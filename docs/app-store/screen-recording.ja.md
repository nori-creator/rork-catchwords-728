# 審査に送る画面録画の撮り方（2026-10-11 の版）

ボタンの名前は、不具合修正の PR #23 の新しいウェルカム画面（Google・Apple・「メールでログイン」・「初めての方は 新規登録」）に合わせてある。録画は PR #23 が入ったビルドで撮る。

Apple の依頼（Guideline 2.1 - Information Needed）の 1 番目:
「**実機**で、**最新の iOS** で撮った画面録画。**アプリの起動から始め**、ふだんの使い方を見せる。アカウント登録・ログイン・アカウント削除を必ず含める」

この録画は審査の担当者だけが見る（公開されない）。3〜6 分が目安。

---

## 準備（録画の前に）

1. **iPhone を最新の iOS にする**: 設定 → 一般 → ソフトウェアアップデート。
2. **審査に出すビルドを TestFlight で入れる**: 不具合を直している作業が終わり、`iOS release` で送ったビルド。返信文の `[BUILD NUMBER]` と同じ番号にする。
3. **アプリを一度消して入れ直す**: ホーム画面でアイコンを長押し → 「アプリを削除」→ TestFlight から入れ直す。最初の画面（ウェルカム画面）から撮るため。
4. **登録に使う新しいメールアドレスを用意する**: 録画の最後に削除するアカウント。
   - Gmail なら `自分の名前+review1@gmail.com` のように `+` と好きな文字を足すと、同じ受信箱に届く別のアドレスになる。
   - **審査用アカウント（App Store Connect の「サインイン情報」に入れたもの）は録画の中で削除しない。** 消すと審査ができなくなる。
5. **身の回りの物を 2〜3 個**（コップ・ペットボトル・本など）を机に置く。明るい場所で。
6. **通知を止める**: コントロールセンターで「集中モード」→「おやすみモード」。録画に個人の通知が映らないようにする。
7. **画面収録をコントロールセンターに入れる**（まだなら）: 設定 → コントロールセンター → 「画面収録」を追加。
8. 録画の中で写真を撮るので、**カメラの許可**は録画中に「許可」を押す（最初の 1 回だけ出る）。

---

## 録画の手順（この順番で）

| # | すること | 画面で見せるもの |
|---|---|---|
| 1 | 画面右上から下にスワイプ → 画面収録（●）を押す → 3 秒待つ | ホーム画面 |
| 2 | CatchWords のアイコンを押して**起動** | ウェルカム画面（Google・Apple・メールでログイン・新規登録） |
| 3 | 画面の一番下の「初めての方は **新規登録**」→ **新しいメールアドレス**とパスワードを入れて「新規登録」 | **アカウント登録** |
| 4 | 「確認メールを送りました。…」と出た時だけ: メールアプリで確認メールを開いてリンクを押す → CatchWords に戻り「確認が終わったので、ログインする」→ パスワードを入れて「ログイン」 | 登録の確認 |
| 5 | 最初の案内を進める:「はじめる」→ 表示言語（日本語か English）→ 1日の学習時間 → 学ぶ目的 → 好きなこと → 通知 →「はじめる」（学ぶ言語の質問は無い。どのアカウントも台湾華語） | 最初の設定 |
| 6 | 「AIへのデータ送信について」の画面を、下まで少しスクロールして見せてから「同意して始める」 | **AI への送信の同意**（審査基準 5.1.2(i)） |
| 7 | カメラのタブ → カメラの許可で「許可」→ コップなどを撮る | 撮影 |
| 8 | 物の輪郭を光がなぞり、物の上に単語のタグが出るまで待つ | 物の上の単語 |
| 9 | 覚えたい単語をタップ → ステッカーと単語と発音が出て、図鑑に入るまで | **中心の機能** |
| 10 | 図鑑のタブ → 今入れた単語を開く → スピーカーのボタンで発音を鳴らす | 単語の詳細 |
| 11 | 設定のタブ → 一番下の方の「サインアウト」→ 確認で「サインアウト」 | **ログアウト** |
| 12 | ウェルカム画面の「**メールでログイン**」→ 同じ新しいアドレスとパスワード →「ログイン」 | **ログイン** |
| 13 | 設定 → 一番下の「アカウントを削除」を開く → 「削除」と入力 →「完全に削除する」→ ウェルカム画面に戻るまで | **アカウント削除**（審査基準 5.1.1(v)） |
| 14 | （できれば）「メールでログイン」で審査用アカウントに入る → 復習のタブで 1 問答える | 復習 |
| 15 | 画面左上の赤い表示（または右上から下にスワイプ）→ 画面収録を止める | — |

- **5 の表示言語は English を選ぶのがおすすめ**（審査の担当者が読める。2〜4 の登録の画面は iPhone の言語のまま）。English にした時は、13 で入力する言葉は「DELETE」（「削除」でも消せる）。ボタンの英語の名前: サインアウト＝Sign out、アカウントを削除＝Delete account、完全に削除する＝Delete permanently、メールでログイン＝Sign in with email。
- 途中で失敗したら、最初から撮り直す（編集でつなげない方が安全）。
- 録画は「写真」アプリに保存される。長すぎる場合（数百 MB）は、「写真」アプリの編集で前後の余計な部分だけ切る。
- 14 で審査用アカウントのメールが画面に映るが、録画は Apple の審査の担当者だけが見るので問題ない。

## 撮った後

1. App Store Connect → アプリ → App Review（審査）→ 該当の提出 → 返信欄に `review-reply.md` の英語の本文を貼る。
2. 録画のファイルを添付して送る。
3. 「App Review Information」の Notes 欄に `review-notes.en.txt` を貼る（Apple の依頼。次の提出でも使われる）。

録画で何か動かなかった時（タグが出ない、発音が鳴らない、削除できない等）は、送らずに Claude に知らせる。
