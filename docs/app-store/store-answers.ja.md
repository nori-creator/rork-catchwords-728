# App Store Connect の質問への答え（2026-10-11 の版）

App Store Connect の画面で入れる項目の答え。根拠はこのリポジトリのコード（`ios/`）と Web 版（`nori-creator/Lovable-catch-words-app`）。
いま App Store Connect に入っている値は `App Store status` ワークフローの報告（ci-previews の `runs/store-status/status.md`）で確かめられる。

---

## 1. 年齢区分（App 情報 → 年齢区分）

2026-01-31 から新しい質問になった（Apple: Upcoming requirements）。**全部「なし」／「いいえ」で 4+**。2026-10-11 の報告では、すでにこの答えで 4+ になっている。

| 質問 | 答え | 理由 |
|---|---|---|
| ペアレンタルコントロール | いいえ | 無い |
| 年齢の確認（Age Assurance） | いいえ | 無い |
| 無制限の Web アクセス | いいえ | アプリの中で自由に Web を見る機能は無い（規約などはアプリの外の Safari で開く。ログインはシステムのログイン画面） |
| ユーザー生成コンテンツ | いいえ | 写真・メモは本人だけが見る。ほかの利用者に配る機能は無い |
| ソーシャルメディア | いいえ | 無い（友達の機能は後回し） |
| メッセージとチャット | いいえ | 無い |
| 広告 | いいえ | iPhone アプリに広告は無い（Web 版だけ AdSense の設定あり） |
| 成人向けのテーマ・医療・性的表現・暴力・ギャンブル・コンテスト・ルートボックス | すべて「なし」 | 該当なし |

※ 友達の機能や、利用者どうしで写真を見せ合う機能を足したら「ユーザー生成コンテンツ」「ソーシャルメディア」が「はい」になり、通報・ブロックの仕組みが必須になる（審査基準 1.2）。

## 2. App のプライバシー（App プライバシー）

「データを収集しますか」→ **はい**。トラッキング → **いいえ**。すべて「ユーザーに関連付けられる」。
`ios/CatchWords/PrivacyInfo.xcprivacy` と同じ内容にする（変える時は両方そろえる）。

| 種類 | 収集 | 用途 | 何のことか |
|---|---|---|---|
| 連絡先情報 → メールアドレス | はい | アプリの機能 | ログイン |
| 連絡先情報 → 名前 | はい | アプリの機能 | 表示名（入れた人だけ） |
| ID → ユーザー ID | はい | アプリの機能・分析 | アカウントの番号。開発者の利用者画面・指標 |
| 位置情報 → 正確な位置情報 | はい | アプリの機能 | 撮った場所（許可した人だけ）。地名と地図、場所のリマインド |
| ユーザーコンテンツ → 写真またはビデオ | はい | アプリの機能 | 撮った写真と切り抜き |
| ユーザーコンテンツ → その他のユーザーコンテンツ | はい | アプリの機能 | メモ・学習の記録・入力した単語 |
| 検索履歴 | はい | アプリの機能・分析 | 「違う単語を入力」で調べた言葉、撮影で見つかった単語の記録 |
| 使用状況データ → 製品の操作 | はい | アプリの機能・分析 | AI の利用回数（1日の上限）、どの候補を選んだか（順位だけ） |
| 購入 → 購入履歴 | はい | アプリの機能・分析 | Web 版の Pro の状態をアカウントに持つ（iPhone アプリには課金なし） |
| ユーザーコンテンツ → 音声データ | いいえ | — | 声で調べる機能は今の版に無い |
| 診断 | いいえ | — | クラッシュの記録などを集める仕組みは入っていない |

- **第三者の AI に送ること**は、App のプライバシーの表では「収集」に含まれる（当社のサーバが受け取って処理するため）。別に、アプリの中の同意画面と、プライバシーポリシー（送り先の会社と国）で示している（審査基準 5.1.2(i)）。
- 2026-10-03 の表から変えた所: 「日記」と「声で調べる」が iPhone から無くなったので説明だけ直した（答えは同じ）。

## 3. 配信する国・地域（価格と配信状況）

2026-10-11 の報告では **175 の国・地域**（中国本土 CHN を含む）に配信する設定。

- **中国本土は外すことを勧める。** 中国本土で配信するには、政府への届け出番号（ICP 備案）を App Store Connect に入れる必要があり、生成 AI の機能には中国の許可も要る。アプリが使う Google の AI は中国本土からは使えないので、どのみち動かない。
- **EU の国々**: EU で配信するには、App Store Connect で「デジタルサービス法（DSA）」の**事業者かどうか（trader status）**の申告が要る。事業者として申告すると、住所・電話番号・メールが EU の App Store のページに公開される。申告しないと EU では配信されない（ほかの国には影響しない）。Web 版で有料の Pro を売っているので、「事業者」に当たる可能性が高い。住所を公開したくなければ、EU を外す。
- それ以外の国はこのままでよい（年齢区分・言語の制限は無い）。
- 変える場所: App Store Connect → アプリ → 価格と配信状況 → 配信状況 → 国または地域の配信状況を編集。

## 5. スクリーンショット

- 2026-10-11 の報告: 日本語に 6.9 インチ（APP_IPHONE_67）が 6 枚。**古い版の画面**（本棚・撮影の 3 つのモード・空の図鑑など、今は無い画面）なので、**今の版の画面に差し替える**。古い画面のままだと、審査基準 2.3（説明と画面がアプリと合っていること）で指摘されることがある。
- 必要な大きさ（Apple: Screenshot specifications）:
  - **6.1/6.3 インチ（Dynamic Island の中くらいの画面）: 1179×2556 または 1206×2622** — 必須
  - **6.9 インチ: 1320×2868・1290×2796・1260×2736**（無ければ 6.5 インチ 1284×2778・1242×2688 が必須）
  - 1 枚以上、10 枚まで。PNG か JPEG。透明部分のない画像。
- 撮る画面（5〜6 枚）: ①物の上に単語のタグが出た画面 ②単語をタップした後（ステッカーと単語）③図鑑 ④単語のページ ⑤復習 ⑥ホームのアルバム
- 実際の写真で撮った画面が一番よい（審査用アカウントに本物の写真で単語を集めてから撮る）。手順は `README.md` の「スクリーンショット」。
- 日本語の画面だけ入れれば、英語・繁体字のページにも同じ画像が出る（言語ごとの画像は任意）。
